# 💳 Razorpay Clone

A fully responsive clone of the Razorpay landing page built using **HTML**, **Tailwind CSS**, and **JavaScript**. This project replicates the modern design, responsive layout, and interactive user interface of the official Razorpay website while demonstrating proficiency in frontend development and utility-first CSS.

## ✨ Features

- 🎨 Pixel-perfect UI inspired by Razorpay's official website

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Bloodyboi/RAZORPAY-CLONE.git
```

### 2. Navigate to the project folder

```bash
cd RAZORPAY-CLONE
```

### 3. Open the project

Simply open `index.html` in your preferred web browser.

> If Tailwind CSS is compiled locally, install dependencies and build the CSS before opening the project.
